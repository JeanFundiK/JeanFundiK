## 🧠 Ma philosophie : Architecte & Bâtisseur

J'adopte une approche de travail fondée sur deux rôles complémentaires :

- 🧭 **L'Architecte :** analyser les besoins, imaginer les solutions, concevoir les systèmes, structurer les prompts et définir les stratégies.
- 🛠️ **Le Bâtisseur :** prototyper les applications, intégrer les technologies, orchestrer les outils d'IA, automatiser les workflows et déployer les solutions.

**Ma conviction :** l'intelligence artificielle doit renforcer la créativité humaine, simplifier le travail et démocratiser l'accès à l'innovation.
